# Prompt Book — AgriSense AI
**Student:** Thummalapalli Eswar
**Domain:** Agriculture — Crop Advisory

### Planning Prompt
Act as an ESE project mentor and define a simple agriculture problem, target users, objectives and functional requirements for an AI-assisted Crop Advisory web application.

### UI Prompt
Design a professional, clean dashboard for a farmer-facing AI crop advisory system. Use a sidebar, summary cards, crop advisory form, weather card, plant image upload, market chart, farming tips and project/about sections. Use a restrained green palette and responsive layout.

### Implementation Prompt
Generate a simple HTML/CSS/JavaScript prototype. Keep the crop recommendation logic transparent and explainable. Include validation-friendly interactions and mobile responsiveness.

### Improvement Prompt
Review the dashboard for visual hierarchy, spacing, readability, mobile responsiveness and clear prototype limitations. Simplify the interface and make it look suitable for an academic ESE demonstration.

### Testing Prompt
Create test cases for navigation, crop recommendation, image upload, chart rendering, responsive layout and empty/error states.
