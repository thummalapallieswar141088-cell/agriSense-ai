# Project Report — AgriSense AI
## AI-Assisted Crop Advisory System
**Student:** Thummalapalli Eswar  
**Domain:** Agriculture (Crop Advisory)

### 1. Problem
Farmers may need to combine crop, weather, plant-health and market information when making field decisions. The project demonstrates a single web interface for these decision-support tasks.

### 2. Objective
Develop a professional web prototype using prompt engineering and AI-assisted tools; demonstrate crop advisory, weather information, plant-image upload, market visualization and farming tips.

### 3. Users
Farmers, agriculture students and academic evaluators.

### 4. Features
Crop Advisory, Weather Insights, Disease Detection workflow, Market Price visualization, Farming Tips, Prompt Book and responsive dashboard.

### 5. AI-Assisted Development
AI was used for requirement planning, interface planning, code generation, refinement, testing and documentation. The Prompt Book records representative prompts and improvements.

### 6. Working
User enters soil, season, rainfall and water availability. The prototype applies simple transparent rules and displays a suggested crop with a reason. Other dashboard modules provide contextual information.

### 7. Technology
HTML, CSS, JavaScript and Chart.js for the prototype chart.

### 8. Limitations
Weather and market values shown in the prototype are illustrative. Disease detection is an upload workflow, not a validated diagnostic model. A production system would use verified APIs, trained/validated ML models, authentication, security and expert-reviewed agricultural guidance.

### 9. Future Scope
Live weather/market APIs, validated disease classification, multilingual support, location-based advisory with consent, farmer profiles, alerts and expert consultation.

### 10. Conclusion
The prototype demonstrates the complete AI-assisted development cycle required by the ESE task: planning, prompting, generation, improvement, testing and explanation.
